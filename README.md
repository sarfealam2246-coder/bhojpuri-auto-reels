# Bhojpuri ReelStudio (24x7 Auto-Reels + Android APK)

## Quick Start
1. Create a new GitHub repository (`https://github.com/new`) named `bhojpuri-auto-reels`.
2. Upload all files from this ZIP into the repository (`main` branch).
3. Open the **Actions** tab on GitHub -> run **Build Android APK** -> download `app-debug.apk` and install on your phone.
4. Open **Bhojpuri ReelStudio** on your phone -> go to **Vault** tab -> save each API Key / ID individually -> tap **Sync All Keys & Config to GitHub**.
5. Done! Your 24x7 Cloud Pipeline will run automatically at **9:00 AM IST**, **7:00 PM IST** (Reels), and **1:00 PM IST** (Tue/Thu/Sun Photo Posts).
